Before you flash

  • Use a desktop version of Google Chrome or Microsoft Edge.
  • Connect the CYD to your computer with a USB data cable.
  • Close any serial monitor using the board's USB port.
  • When prompted, select the board's serial port and approve installation.

Use the installer for your display size. These installers are for the original ESP32 CYD, not ESP32-S3 or other CYD variants. Flashing replaces the firmware currently on the device.
