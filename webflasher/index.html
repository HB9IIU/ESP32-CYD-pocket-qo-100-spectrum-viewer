Pocket QO-100 Spectrum Viewer

Install the receive-only spectrum viewer on a Classic ESP32 CYD 2.8-inch (ESP32-2432S028R).

Before you flash

  • Use a desktop version of Google Chrome or Microsoft Edge.
  • Connect the CYD to your computer with a USB data cable.
  • Close any serial monitor using the board's USB port.
  • When prompted, select the board's serial port and approve installation.

This firmware is for the original ESP32 CYD, not ESP32-S3 or other CYD variants. Flashing replaces the firmware currently on the device. The viewer is receive-only and does not connect to Wi-Fi.

Source code and build instructions on GitHub.
